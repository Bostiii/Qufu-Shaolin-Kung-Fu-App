# Security Policy / 安全策略

This document is provided in both English and Chinese for convenience.
The English version is the authoritative legal and operational text.
The Chinese text is a translation for reference only.

------------------------------------------------------------
English Version
------------------------------------------------------------

We take the security of this project seriously. If you believe you have found a security vulnerability in the Qufu Shaolin Kung Fu App, please do not open a public issue first.

## Reporting a Vulnerability / 报告漏洞

Please report vulnerabilities using one of the following methods:

- GitHub Security Advisory (recommended): https://github.com/Bostiii/Qufu-Shaolin-Kung-Fu-App/security/advisories/new
- Email: security@yourdomain.com

Please include:
- a description of the vulnerability
- affected version or commit
- steps to reproduce
- potential impact
- any suggested remediation

We ask that you allow us time to investigate and respond before making the issue public.

## Response Timeline / 响应时间

We will do our best to:
- acknowledge receipt within 5 business days
- assess the issue within 10 business days
- provide updates while we investigate
- notify you when a fix is ready or when a decision is made

## Scope / 范围

This policy applies to security issues in the project code, application behavior, and infrastructure used by the project.

## Non-security Issues / 非安全问题

For general bugs, feature requests, and questions, please use GitHub Issues:

https://github.com/Bostiii/Qufu-Shaolin-Kung-Fu-App/issues

## Responsible Disclosure / 负责任披露

We appreciate responsible disclosure and will work with researchers and contributors to address vulnerabilities in a timely and professional manner.

## Supported Versions / 受支持版本

We currently support the latest version on the default branch.

If a vulnerability is reported in an older version, we will assess whether a fix is practical and appropriate.
